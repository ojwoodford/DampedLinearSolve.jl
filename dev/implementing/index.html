Implementing the contract

A package with its own storage (a block-structured Hessian, a reduced system) implements the contract by defining a subtype of AbstractLinearSystem and methods of DampedLinearSolve's functions for it. An optimizer written against the contract then runs on it unchanged.

What to define

For a system type MySystem:

  1. Construction: a method of makelinearsystem (or maketallsystem) for your prototype type, and, if the prototype has checks, of checkhessian (or checkjacobian, jacobian_ncols, jacobian_nrows, check_jacobian_linsolver). Add structurekey for a prototype that is not a matrix, so that a caller caching systems can recognise its structure.
  2. Filling: getA, getb, getx and zero!; for tall storage also getJ, getr, gradient! and markstale!.
  3. Damping and solving: dampen! with both signatures, and solve! for each solver you accept, returning a SolveStatus, leaving A and b as filled.
  4. Queries: max_diag, getdiag!, quadform for your storage (or a three-argument LinearAlgebra.dot), dampingfloor and isfinitesystem. quadratic_model_change has a generic method built on quadform and getb.
  5. The spare system: copy_structure and sharex.
  6. The conformance hooks, for storage other than a Matrix, MMatrix or SparseMatrixCSC: conformance_matrix, conformance_fill!, and where needed conformance_fillb! and conformance_traits.

A system that reduces itself to a standard matrix (eliminating some variables, say) can hold a DampedLinearSolve system of that matrix's type, fill it, solve it through the contract, and back-substitute, so that it inherits the standard solvers rather than writing its own.

The conformance check

Run check_linear_system in your test suite for each solver you accept. It builds fresh systems with the function you pass, fills them through the hooks, and checks every rule that can be checked from outside; it throws naming the first rule broken.

julia> check_linear_system(s -> makelinearsystem(zeros(4, 4), s); n = 4, linsolvers = (:auto, :cholesky, :ldl, :qr))

julia> check_linear_system(s -> maketallsystem(6, 4, s); n = 4, linsolvers = (:auto, :qr))
